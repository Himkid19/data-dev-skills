# MPC 与 JR/T 0304 元数据命名对照
| MPC 英文命名结构 | JR/T 0304 中文元数据结构 | 作用 |
| ---- | ---- | ---- |
| Modifier 修饰词 | 对象词（限定词） | 限定：时间、来源、币种、维度、范围，可选、可多个 |
| Part 基词 | 特性词（主体词） | 核心业务实体 / 指标本体，必须存在，语义中心 |
| Classifier 类词 / 量词 | 表示词 | 描述指标类型：日期、金额、数量、比率、代码，标识度量类型 |

> JR/T0304 原文结构：**对象词 + 特性词 + 表示词**（中文业务名称）
>
> MPC：**Modifier + Part + Classifier**（英文物理字段名，券商境外主数据模型改造出来的简称，不是国标原名）
>
> 举例：收盘价 -> 不复权收盘价 -> clos_pric

| 中文类词 | 英文 | 释义 | 适用场景 & 证券期货业备注 |
| ---- | ---- | ---- | ---- |
| 价格 | pric | 单位标的报价，未乘以数量 / 合约乘数；单位可为点数、净价、单价，不一定是货币 | 行情：收盘价、结算价、开盘价、买卖价。⚠️金融期货：股指 / 国债期货 price 是点 / 百元净价，不等于人民币金额 |
| 金额 | amt | 货币合计总值，已完成「单价 × 数量 × 乘数」计算；资金口径，单位为货币 | 成交金额、股利金额、手续费金额、交割货款、资金划转金额 |
| 价值 | val | 广义估值 / 市值；可指单合约名义价值、持仓市值，介于 price 与 amount 之间 | 持仓市值、合约价值、资产估值；期货：一手名义价值常用 value/notional |
| 名义金额 | theor | 衍生品 / 期货专用，合约名义本金，理论参考基数，不一定实际交割现金 | 国债期货、利率衍生品、互换名义本金；建议独立，不混用 amount |
| 数量 | qty | 标的、合约、手数的实物 / 合约计数 | 股票股数、期货手数、期权合约数量 |

| 收益率 | yield | 投资年化回报 | 债券到期收益率、持有期收益率 |
| 溢价 | prem | 期权权利金、溢价价差 | 期权权利金、升贴水溢价 |
| 价差 | sprd | 两个价格的差值 | 买卖价差、跨期价差 |
| 代码 | cd | 业务编码，主数据标识 | 证券代码、合约代码、交易所代码 |

| 标识 | id | 唯一内部主键标识 | 内部主体 ID、持仓 ID |

| 日期 | dt | 日期（年月日） | 交易日、到期日、交割日、登记日 |
